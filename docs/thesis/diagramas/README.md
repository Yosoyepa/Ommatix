# Diagramas de arquitectura

Las cuatro fuentes `.mmd` conservan diagramas Mermaid editables: contexto, componentes, secuencia de acción y estado de snapshot. Su sintaxis no se ejecutó con Mermaid en esta entrega.

Se incluyen también cuatro fuentes `.dot` para Graphviz; los `.svg` no se versionan y se generan con `dot -Tsvg archivo.dot -o archivo.svg`. La edición PDF/Word, que se conserva fuera del repositorio, incorpora estas vistas; `03_flujo_accion` es una vista de flujo del mismo contrato, no una exportación literal del diagrama de secuencia Mermaid.

Las mismas vistas, con etiquetas en inglés, están en [`../../diagrams/`](../../diagrams/README.md). Cada figura es una especificación del diseño propuesto, no evidencia de una ejecución del motor. La política de acción y los estados se definen normativamente en los capítulos 02, 04 y 07.
